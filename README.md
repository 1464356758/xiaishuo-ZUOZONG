## 创建新书

系统优化完成并收到明确开书指令后，可使用《启动新书.txt》初始化。需要创建多部小说时，把 `初始化系统包.zip` 解压到各自的新仓库，分别生成新书身份；空包的仓库链接、平台和题材均为空。

原有默认目标仍为100章、每章8000—10000汉字、最多3轮局部修订、每5章回看。是否调整这些规则，留待后续优化决定。

阅读器代码已复制，本次没有部署新网站，也没有修改原来的阅读网站。网页不调用GPT，不会在关闭聊天后自动写作或投稿。
